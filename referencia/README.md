# Referencia: prototipo anterior del panel de recepción

`panel-recepcion-artefacto.html` es un prototipo que se hizo antes de este
proyecto. Se guarda para no perder qué hacía, pero **no se publica ni se usa**:

- Guardaba las reservas en Google Calendar a través de un servicio externo que
  solo funcionaba dentro de la herramienta donde se creó.
- Revisaba la contraseña en el navegador: cualquiera la leía con "ver código
  fuente". La que traía está quemada.

Sirve como lista de lo que el panel real tiene que hacer: reservas de hoy y de
la semana, mesas ocupadas ahora, marcar "llegó", editar y cancelar.
