# Referencia: panel de recepción

`panel-recepcion-artefacto.html` es el panel que se hizo como artefacto de
Claude (claude.ai/public/artifacts/2eaee93c-45cf-4a2a-b944-ed944ee506e7).
Se guarda para no perder qué hacía, pero **no se publica ni se usa**:

- Guarda las reservas en Google Calendar pidiéndoselo a Claude con texto
  ("crea un evento…") y leyendo la respuesta. Solo funciona dentro de
  claude.ai; fuera de ahí, la llamada a api.anthropic.com no tiene llave.
- Revisaba la contraseña en el navegador: cualquiera la leía con "ver código
  fuente". La que traía está quemada.

Sirve como lista de lo que el panel real tiene que hacer: reservas de hoy y de
la semana, mesas ocupadas ahora, marcar "llegó", editar y cancelar.
